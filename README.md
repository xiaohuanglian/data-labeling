# 数据标注

本地网页，四个功能互不调用，从首页点进去。

```bash
cd "/Users/mac/Desktop/数据标注"
./run.sh
```

浏览器打开 http://127.0.0.1:8780

| 入口 | 做什么 | 文件名 |
|---|---|---|
| 非量化命名 `/nq-name/` | 看一条，四机按同一序号改名。对错写进文件名。 | `P005_A01_L_E00_V01_C0` |
| 非量化标注 `/nq-label/` | 已按六段式命名后，标每个 rep 的起止帧。不抽帧。 | 不改名 |
| 量化命名 `/q-name/` | 看一条，四机同步粗命名，做法写入 `对照表.csv`。 | `sq_s004_t01_c0` |
| 量化标注 `/q-label/` | 读对照表，选一个机位标起始点和峰值，四机一起切。 | 导出 `sq_s004_r001_c0` |

量化命名的动作和档位：260825 的 10 个动作都在。股四头肌拉伸、侧抬腿的档位按 260922 补充指导（真不足、太低/标准/太高）。目标做法不进文件名。切分后的 r 号只写在对照表的「切分后建议r」列。

代码来源：非量化命名来自「视频命名」，非量化标注来自「视频处理-序列-lishi」，量化标注来自「视频处理」的线下切分。原目录没有改。
